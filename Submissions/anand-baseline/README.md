# Anand Baseline Pipeline

Baseline SDRF metadata extraction pipeline for the
"Harmonizing the Data of Your Data" Kaggle competition.

## Overview
This submission implements a conservative, rule-based + normalization-first
approach to extracting SDRF metadata from proteomics publications.
